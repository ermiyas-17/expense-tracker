# expense-tracker
💰 Expense Tracker

A simple command-line expense tracker built with Python. This project helps users record and manage expenses while practicing Python programming and JSON file handling.

✨ Features

 Add new expenses
 View saved expenses
 Search expenses by category
 Delete expenses by category
 Store data in a JSON file
 Validate user input

🛠️ Technologies Used

- Python
- JSON
- Git and GitHub


Requirements

- Python 3
- A terminal or command-line environment

Installation

1. Clone the repository:
   
   git clone https://github.com/ermiyas-17/expense-tracker.git

2. Open the project folder:
   
   cd expense-tracker

3. Run the program:
   
   python expense_tracker.py
